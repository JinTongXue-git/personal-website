# AI日志记录command

## 一、概述

- **名称**: AI日志记录器
- **版本**: 1.0.0
- **用途**: 跨项目记录AI操作日志，便于追踪和复盘

---

## 二、设计原则

| 原则 | 说明 |
|------|------|
| 时间准确性 | 通过网络时间API获取真实时间，避免系统时间偏差 |
| 层级清晰 | 按年/月/日三层文件夹结构组织日志 |
| 易于查找 | 日志文件名包含时间和简短描述 |
| 人类可读 | 使用Markdown格式记录，方便人阅读 |
| 跨项目通用 | 不依赖特定项目，可直接复用 |

---

## 三、文件结构

### 3.1 目录层级

```
ai-log/
├── 2026/                    # 年份文件夹（4位数字）
│   ├── 05/                  # 月份文件夹（2位数字，补零）
│   │   ├── 17/              # 日期文件夹（2位数字，补零）
│   │   │   ├── 1443_创建AI日志Skill.md
│   │   │   └── 1520_更新文件结构.md
│   │   └── 18/
│   │       └── 0915_修复登录bug.md
│   └── 06/
│       └── 01/
│           └── 1030_优化首页性能.md
└── .gitkeep
```

### 3.2 文件命名规则

**格式**: `HHMM_描述(10-20字).md`

**示例**:
- `1443_创建AI日志Skill.md`
- `1520_更新文件结构.md`
- `0915_修复登录bug.md`

**说明**:
- `HHMM`: 24小时制时间（小时+分钟）
- `描述`: 10-20字的简短描述，说明本次操作内容
- 特殊字符替换: `/ \ : * ? " < > |` 替换为 `-`

---

## 四、日志模板

```markdown
# [时间] - [操作描述]

## 一、操作概览

| 项目 | 内容 |
|------|------|
| 时间 | YYYY-MM-DD HH:MM:SS |
| 类型 | 创建/修改/删除 |
| 文件 | 文件路径列表 |
| 操作人 | AI Assistant |

## 二、操作前后

**前**: 操作前状态  
**后**: 操作后状态

## 三、操作内容

步骤描述...

## 四、思考过程

AI决策理由、问题解决思路...

## 五、后续建议

待处理事项、优化方向...
```

---

## 五、执行流程

1. 获取网络时间 → 检查年/月/日目录 → 不存在则创建
2. 生成文件名（时间+描述）→ 按模板写入内容

---

## 六、复用说明

复制本文件到目标项目，创建`ai-log`目录即可使用。
