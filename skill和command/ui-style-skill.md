# UI风格统一Skill

## 一、概述

- **名称**: UI风格统一器
- **版本**: 1.0.0
- **用途**: 保证前端页面风格一致性，参考 `https://blog.prorisehub.com/` 风格 + 大气磅礴设计理念

---

## 二、设计原则

| 原则 | 说明 |
|------|------|
| 大气磅礴 | 全屏沉浸式体验，内容与页面融合 |
| 极简主义 | 去除冗余装饰，减少视觉干扰 |
| 无边框感 | 避免嵌套盒子，保持视觉通透 |
| 留白有度 | 合理留白，提升层次感 |
| 响应适配 | 适配各种屏幕尺寸 |

---

## 三、颜色方案

### 3.1 主色调

| 颜色 | 用途 |
|------|------|
| `#1a1a2e` | 深色背景（主背景） |
| `#16213e` | 卡片背景 |
| `#0f3460` | 强调色/hover效果 |
| `#e94560` | 主色调/按钮/链接 |
| `#ffffff` | 主文字 |
| `#a0a0a0` | 次要文字/占位符 |

### 3.2 配色规则

- 背景：深色系为主，营造沉稳大气感
- 文字：高对比度，确保可读性
- 强调：鲜明但不刺眼的点缀色

---

## 四、组件规范

### 4.1 导航栏

- **高度**: 60px
- **背景**: 半透明毛玻璃效果
- **布局**: 左侧Logo + 右侧导航链接
- **交互**: hover时文字高亮，平滑过渡

### 4.2 按钮

| 类型 | 样式 | 场景 |
|------|------|------|
| 主按钮 | 纯色填充，圆角8px | 主要操作 |
| 次按钮 | 边框样式，圆角8px | 次要操作 |
| 文字按钮 | 仅文字，无背景 | 链接跳转 |

### 4.3 卡片

- **风格**: 无边框，轻微阴影
- **圆角**: 12px
- **间距**: 卡片间距20px
- **hover**: 轻微上浮效果

### 4.4 输入框

- **样式**: 底部边框线，无边框
- **聚焦**: 边框高亮，无额外装饰
- **占位符**: 灰色浅色调

---

## 五、布局规范

### 5.1 整体布局

- **最大宽度**: 1200px（内容居中）
- **侧边距**: 自动（响应式）
- **内容区**: 全屏宽度，减少分割感

### 5.2 特殊要求

**AI聊天窗口示例**:
- 输入框固定底部，全屏宽度
- 消息内容与背景融合，无边框
- 仅用内边距区分内容区域
