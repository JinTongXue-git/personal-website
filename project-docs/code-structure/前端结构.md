# 前端文件结构

## 目录结构

```
src/
├── assets/          # 静态资源
├── components/      # 公共组件
├── views/           # 页面组件
├── router/          # 路由配置
├── stores/          # 状态管理
├── api/             # API接口
├── utils/           # 工具函数
├── styles/          # 全局样式
└── App.vue          # 根组件
```
