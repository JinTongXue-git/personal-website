# 后端文件结构

## 目录结构

```
src/
├── controller/      # 控制器层
├── service/         # 业务逻辑层
├── repository/      # 数据访问层
├── model/           # 数据模型
├── dto/             # 数据传输对象
├── config/          # 配置类
├── security/        # 安全相关
├── exception/       # 异常处理
└── Application.java # 启动类
```
