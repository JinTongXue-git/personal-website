# 个人网站项目描述

## 一、项目定位

个人网站是一个综合性展示平台，包含**前台展示**和**后台管理**两部分。

### 1.1 前台展示
- 个人信息展示
- 项目成果展示
- 技术博客
- AI聊天功能
- 作品集展示

### 1.2 后台管理
- 内容管理
- 数据管理
- 权限管理
- 内容发布

---

## 二、核心功能

| 页面 | 功能 |
|------|------|
| 首页 | 个人介绍、最新动态 |
| 作品页 | 项目作品集展示 |
| 博客页 | 技术文章列表 |
| 聊天页 | AI克隆聊天 |
| 后台 | 内容管理系统 |

---

## 三、设计理念

- **大气磅礴**: 全屏沉浸式体验
- **极简主义**: 去除冗余装饰
- **响应设计**: 适配各种设备

---

## 四、技术栈

- **前端**: Vue3 + TypeScript
- **后端**: Spring Boot
- **数据库**: MySQL
- **样式**: Tailwind CSS
