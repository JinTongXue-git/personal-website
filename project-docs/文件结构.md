# 项目文件结构

## 一、整体架构

```
personal-website/
├── ai-log/                 # AI操作日志
├── project-docs/           # 项目文档
├── personal-website-backend/  # 后端代码
├── personal-website-frontend/ # 前端代码
├── skill/                  # 技能定义
└── README.md
```

## 二、目录说明

| 目录 | 用途 |
|------|------|
| ai-log | AI操作日志（年/月/日层级） |
| project-docs | 项目文档、接口定义、功能描述 |
| personal-website-backend | 后端项目代码 |
| personal-website-frontend | 前端项目代码 |
| skill | 可复用技能定义文档 |

## 三、详细结构

### 3.1 project-docs

```
project-docs/
├── 双项目开发构想.md
├── 个人网站描述.md
├── 文件结构.md
├── tech-stack/          # 技术栈说明

└── code-structure/       # 代码结构说明
    ├── 前端结构.md
    └── 后端结构.md
```
