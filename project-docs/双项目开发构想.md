# 双项目开发构想

本次计划同时开发两个项目，两个项目各有独立功能和技术方向，同时可以互相借鉴技术、复用功能，形成**螺旋递增开发模式（双向参考、持续迭代、越开发越完善的成长模式）**。

依托AI辅助开发，我可以省去大量基础排错、调试的时间，**把精力集中在项目架构、功能设计和技术深耕**上。两个项目互相赋能、同步升级，避免单一开发的技术局限，实现项目成果和个人技术能力的双向提升。

## 一、两大核心项目介绍

本次开发包含两个核心项目，分别是**个人网站项目**、**无线画布AI创作平台**项目。两个项目定位不同、功能独立，同时技术互通、可以互相借力优化迭代。

### （一）个人网站项目

个人网站是基础技术项目，整体分为**展示页面（对外给别人看的页面）+后台管理系统（自己用来改内容、管数据的后台）**两部分，主要用来展示个人作品、沉淀前后端开发经验。

前台核心作用是展示个人信息、项目成果、作品内容，供访客浏览查看。后台管理系统是配套的独立功能模块，用来更新页面内容、管理数据、设置使用权限、发布内容，实现网站内容的自主管控。

这个项目主要积累基础的网页搭建、页面排版、数据交互、权限管理等通用技术，能为第二个AI项目提供基础的技术支撑。

### （二）无线画布AI创作平台项目

无线画布是参考ComfyUI生图功能，**零代码拖拽式AI创作平台（不用写代码，靠鼠标拖拽就能做AI生图工作流）**。核心亮点是可视化节点创作、自定义AI生图流程、用户作品共享复用。平台整体分为首页、工作台、个人中心三个核心页面，各页面功能衔接完整、使用闭环。

#### 1. 首页：作品浏览与复用广场

首页设计参考B站的内容展示逻辑，采用**卡片式瀑布流布局（作品卡片整齐错落排列，下拉持续加载）**，集中展示所有用户公开的AI创作作品和自定义工作流。

页面支持作品分类、筛选，方便浏览各类创作案例。最核心的功能是一键复用：看到别人优质的作品和创作流程，可直接导入自己的工作台，也能直接基于公开作品二次创作，大幅降低AI创作的门槛。

#### 2. 工作台：核心AI创作页面

工作台是平台的核心创作区域，采用**二维无限画布（可以无限放大、缩小、拖拽的空白创作平面）**，全程零代码拖拽操作，靠组合功能节点、连接节点线条，就能搭建完整的AI生图流程。

用户可以在画布上随意添加、拖拽、摆放各类功能节点，每个节点都是独立卡片，可自行输入AI提示词。从节点拉出连接线并松开后，页面会弹出功能选择窗口，支持提示词优化、AI生图、智能对话、二次编辑等操作，可根据创作需求一步步递进创作。

整个创作过程可视化，所有节点、连线、功能逻辑清晰可见。用户无需关注复杂的底层代码，只需要把控**输入规则和输出效果**。比如可以设定规则：上传人物上半身照片，即可精准生成人物三视图，打造专属、可复用的标准化AI创作流程。

工作台支持多种创作方式，可新建空白项目、打开历史作品、导入全网公开工作流，满足文生图、图生图、图像提取、画面优化等各类AI创作需求。

#### 3. 个人中心：个人作品管理后台

个人中心是用户的专属后台，用来统一管理自己的创作资产。这里会集中展示所有已保存、已创作、已发布的作品和工作流，形成个人专属作品集。

用户可以在这里管理私密作品、编辑公开作品、更新或下架已发布的内容，实现作品的全流程管理。创作完成并调试好的工作流，可直接保存并一键发布到平台首页，供其他用户浏览、导入、二次创作，形成完整的创作、发布、复用、迭代闭环。

## 二、双项目螺旋循环迭代机制

两个项目不会分开独立开发，而是形成**互相赋能、循环升级**的成长体系。二者既有专属的独立技术，也有大量通用技术，可以互相借鉴、复用经验。

个人网站沉淀的网页搭建、页面交互、数据管理、权限系统、内容发布等基础技术，可以直接用到无线画布的页面搭建、后台管理、用户中心、作品发布等模块中。

反过来，无线画布打磨的拖拽交互、节点联动、AI接口适配、用户生态运营等新技术，也能优化个人网站的页面体验、拓展更多功能。

开发过程中，两个项目遇到的问题、总结的优化方法可以双向通用，一个项目的技术经验可以快速落地到另一个项目，让两个项目持续迭代升级，稳步提升整体开发水平。
