# 聊天接口定义

## 一、发送消息

**POST** `/api/chat/message`

请求体：
```json
{
  "content": "string"
}
```

响应：
```json
{
  "id": "number",
  "content": "string",
  "sender": "string",
  "timestamp": "datetime"
}
```

## 二、获取消息列表

**GET** `/api/chat/messages`

参数：
- `page`: 页码（默认1）
- `size`: 每页数量（默认20）

响应：
```json
{
  "content": [
    {
      "id": "number",
      "content": "string",
      "sender": "string",
      "timestamp": "datetime"
    }
  ],
  "totalElements": "number"
}
```
