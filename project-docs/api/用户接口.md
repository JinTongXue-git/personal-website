# 用户接口定义

## 一、登录接口

### 1.1 登录

**POST** `/api/auth/login`

请求体：
```json
{
  "username": "string",
  "password": "string"
}
```

响应：
```json
{
  "token": "string",
  "user": {
    "id": "number",
    "username": "string",
    "email": "string"
  }
}
```

### 1.2 注册

**POST** `/api/auth/register`

请求体：
```json
{
  "username": "string",
  "email": "string",
  "password": "string"
}
```

响应：
```json
{
  "id": "number",
  "username": "string",
  "email": "string"
}
```

## 二、用户信息

### 2.1 获取当前用户

**GET** `/api/user/me`

响应：
```json
{
  "id": "number",
  "username": "string",
  "email": "string",
  "avatar": "string"
}
```
