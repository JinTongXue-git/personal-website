# 博客接口定义

## 一、文章列表

**GET** `/api/posts`

参数：
- `page`: 页码（默认1）
- `size`: 每页数量（默认10）
- `category`: 分类ID（可选）
- `tag`: 标签ID（可选）

响应：
```json
{
  "content": [
    {
      "id": "number",
      "title": "string",
      "summary": "string",
      "cover": "string",
      "category": "string",
      "tags": ["string"],
      "createdAt": "datetime"
    }
  ],
  "totalElements": "number",
  "totalPages": "number"
}
```

## 二、文章详情

**GET** `/api/posts/{id}`

响应：
```json
{
  "id": "number",
  "title": "string",
  "content": "string",
  "cover": "string",
  "category": "string",
  "tags": ["string"],
  "createdAt": "datetime",
  "updatedAt": "datetime"
}
```

## 三、创建文章

**POST** `/api/posts`

请求体：
```json
{
  "title": "string",
  "content": "string",
  "cover": "string",
  "categoryId": "number",
  "tagIds": ["number"]
}
```

响应：同文章详情
